# 两个兴趣建模 Idea

## 共同思路：先预测兴趣，再预测商品

不同用户的行为序列可能不同，但他们可能属于兴趣相近的人群。我们希望让模型从具体行为中提炼共享的兴趣表示，先预测用户兴趣，再根据兴趣预测下一商品。

整体采用两个阶段：**SFT 激活兴趣，RL 强化兴趣。** SFT 让模型学会从历史行为识别、生成兴趣，并利用兴趣推荐商品；RL 再以推荐效果为奖励，强化有助于推荐的兴趣选择和商品生成。

## Idea 1：从行为序列中量化兴趣

先用 Qwen embedding 模型编码用户的历史商品标题序列，再通过 VQ-VAE 将历史向量压缩为离散兴趣 token。兴趣 token 作为用户历史与下一商品之间的中间表示。

```text
兴趣标签构建：历史标题序列 → embedding → VQ-VAE → 兴趣 token
推荐模型：历史商品 SID → 兴趣 token → 下一商品 SID
```

**SFT 阶段进行兴趣激活：** 用离线构建的兴趣 token 监督模型，让模型学会从历史中预测兴趣，并在兴趣条件下预测商品。

**RL 阶段进行兴趣强化：** 以最终推荐效果为奖励，联合优化兴趣与商品的生成，使模型更倾向于选择能够带来有效推荐的兴趣表示。

## Idea 2：先概括字符兴趣，再量化并对齐语义

先让更强的生成式 Qwen3 根据用户历史行为，输出少于200个字符的兴趣描述或用户画像；再用 embedding 模型编码这段文本，通过 VQ-VAE 转为三个离散兴趣 token。

```text
兴趣标签构建：历史标题序列 → 强 Qwen3 → 字符兴趣 → embedding → VQ-VAE → 兴趣 token
推荐模型：历史商品 SID → 兴趣 token → 下一商品 SID
辅助任务：兴趣 token → 字符兴趣；字符兴趣 → 兴趣 token
```

**SFT 阶段进行兴趣激活与语义对齐：** 除了监督“历史→兴趣→商品”，还加入兴趣 token 与字符兴趣的双向预测任务，让离散兴趣表示与可读的兴趣语义建立联系，类似商品 SID 与商品标题之间的双向对齐。

**RL 阶段进行兴趣强化：** 在已有语义对齐的基础上，以推荐效果为奖励，强化对下一商品预测有帮助的兴趣选择和商品生成。

字符兴趣由教师离线生成。第一版只使用与推荐模型相同的最多10件历史商品，后续可探索更长历史；不包含待预测商品。在线推荐仍由学生模型完成“历史→兴趣→商品”。

两个 idea 的主要区别是：第一个直接量化行为序列向量；第二个先通过强模型得到显式的兴趣描述，再量化，并通过双向辅助任务把文本语义对齐到兴趣 token。
